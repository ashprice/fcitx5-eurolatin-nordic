# fcitx5-eurolatin-nordic

This is an IME for [fcitx5](https://fcitx-im.org/wiki/Fcitx_5) that enables one to type the major North Germanic languages: Norwegian (bokmål, nynorsk), Swedish, Danish, Faroese, and Icelandic.

There is also some support for characters used in manuscripts and diplomatic editions of Old Norse texts, though such coverage is not comprehensive - I feel it is best to cover the most common letters used in normalised citations, and to use a separate layout for comprehensive coverage, so as to not overburden regular typing with dead keys. Similarly, special characters used in the orthography of several minority languages are also considered out-of-scope for this layout.
